# Cavlu Homebrew tap

Homebrew tap для [Cavlu](https://github.com/plexideas/cavlu-releases), нативного корректора русской и английской раскладок для macOS 14+ на Apple Silicon и Intel.

## Установка

На новом Mac один раз подключите tap, затем установите приложение короткой командой:

```sh
brew tap plexideas/cavlu
brew install --cask cavlu
open -a Cavlu
```

Если Homebrew сообщает `untrusted tap`, один раз выполните `brew trust --cask plexideas/cavlu/cavlu`, затем повторите `brew install --cask cavlu`. Это разрешение только для данного cask, не отключение Gatekeeper.

Разрешите приложению «Универсальный доступ» и «Мониторинг ввода» в системных настройках. Автоисправление по умолчанию выключено.

Пакет Universal, Xcode и Git для запуска не нужны. ZIP загружается из [публичных GitHub Releases](https://github.com/plexideas/cavlu-releases/releases/latest), Homebrew проверяет настоящий SHA-256 архива. Приватные исходники и исследовательский архив не публикуются.

Для сборки без нотарификации macOS может заблокировать первый запуск. Если доверяете загрузке, разрешите её штатной кнопкой «Всё равно открыть» в «Конфиденциальность и безопасность». Cask не отключает Gatekeeper и не снимает карантин автоматически.

```sh
brew update
brew upgrade --cask --greedy cavlu
brew uninstall --cask cavlu
```

Обычное удаление сохраняет настройки. `brew uninstall --zap --cask cavlu` удаляет также пользовательские правила и обученные исключения из `~/Library/Application Support/project-23`. Перед удалением завершите приложение и отключите запуск при входе.

После установки Cavlu автоматически проверяет подписанные выпуски при запуске и каждый час, скачивает обновления и устанавливает их при выходе либо после минуты бездействия с закрытыми окнами Cavlu. Настройки сохраняются. В меню есть ручная проверка и отключение автообновлений. Ad-hoc подпись не гарантирует сохранения разрешений macOS между версиями.

Это пользовательский tap, не официальный `homebrew/cask`. Поэтому на новом Mac необходим однократный `brew tap plexideas/cavlu`; после него работает `brew install --cask cavlu`.
